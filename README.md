# מערכת הקבלות — אריאל יוסופוב עיצוב אתרים

אתר פרטי וסגור בסיסמה להפקת קבלות (עוסק פטור), עם שמירה מוצפנת ב-Google Drive, הדפסה ושליחת PDF.

**כתובת האתר (אחרי הפעלת GitHub Pages):** https://yosupovariel-dot.github.io/Ariel-Receipts/

---

## מה יש במערכת

- **הפקת קבלה בשלושה צעדים** — לקוח, עבור מה, תשלום. תצוגה מקדימה חיה של הקבלה בזמן ההקלדה.
- **מספור אוטומטי ורציף** — מתחיל מ-80018, בלי דילוגים ובלי כפילויות.
- **קבלה לפי החוק** — כל הפרטים הנדרשים, "מקור" / "העתק נאמן למקור", חתימה. קבלה שהופקה לא נמחקת ולא נערכת — רק מבוטלת (עם חותמת "מבוטלת").
- **שליחה**: שיתוף PDF ישיר לוואטסאפ/מייל מהטלפון, הורדת PDF, הדפסה.
- **ארכיון מסודר** לפי שנים וחודשים, חיפוש, סיכום שנתי וייצוא לאקסל.
- **לקוחות** נשמרים אוטומטית — בפעם הבאה מקלידים שתי אותיות והפרטים מתמלאים.
- **שכפול** קבלה ללקוח קבוע בלחיצה אחת.
- **מעקב תקרת עוסק פטור** והתראה בהתקרבות.
- **Google Drive** — כל קבלה חדשה נשמרת אוטומטית כ-PDF בתיקיית השנה; הקבלות הקיימות ב-Drive מוצגות באתר.
- **נגישות** (ת"י 5568 / WCAG AA), תפריט נגישות, הצהרת נגישות, תנאי שימוש ומדיניות פרטיות.
- עובד מצוין בטלפון — אפשר "להוסיף למסך הבית" כמו אפליקציה.

קיצורי מקלדת: `N` — קבלה חדשה. `Ctrl+Enter` — הפקה.

## איפה הנתונים נשמרים

**ב-Google Drive שלך בלבד**, בתיקיית הקבלות:
- קובץ הנתונים של המערכת — **מוצפן** (AES-256-GCM, מפתח שנגזר מהסיסמה ב-PBKDF2 600,000 סבבים), בתיקייה `_גיבוי נתוני מערכת`, עם **גיבוי יומי אוטומטי** (60 יום אחרונים + גיבוי חודשי קבוע).
- קובץ PDF של כל קבלה — בתיקיית השנה (`קבלות 2026` וכו'; נוצרת לבד אם חסרה).
- בנוסף נשמר עותק מוצפן בדפדפן, כך שאפשר לעבוד גם בלי אינטרנט — השינויים עולים ל-Drive כשהחיבור חוזר.

הסיסמה לא כתובה בשום מקום. ממנה נגזרים גם מפתח ההצפנה וגם קוד הגישה לסקריפט ב-Drive — כך שבמכשיר חדש פשוט נכנסים עם הסיסמה, בלי קודים נוספים. אין שחזור סיסמה, לכן לרשום אותה במקום בטוח. החלפת סיסמה (הגדרות ← אבטחה) מעדכנת אוטומטית גם את הסקריפט.

ניתוק אוטומטי אחרי 30 דקות ללא פעילות, נעילה זמנית אחרי 5 ניסיונות כניסה שגויים.

## הפעלה — פעם אחת

1. **האתר** מתפרסם אוטומטית ב-GitHub Pages (קובץ `.github/workflows/pages.yml`): https://yosupovariel-dot.github.io/Ariel-Receipts/
2. **כניסה:** שם משתמש `אריאל` והסיסמה.
3. **חיבור Drive:** באתר ← **Drive**. מדביקים את הקישור לתיקיית הקבלות ← "יצירת הקוד" ← "העתקת הקוד". ב-[script.google.com](https://script.google.com/home): מוחקים הכל, מדביקים, שומרים, מריצים `testSetup` ומאשרים הרשאות. אחר כך **"לפריסה" ← "פריסה חדשה" ← "אפליקציית אינטרנט"** (הפעלה בתור: אני, גישה: כל אחד), ומדביקים באתר את הכתובת שמסתיימת ב-`/exec`.

הסקריפט רץ בחשבון הגוגל שלך וניגש רק לתיקיית הקבלות. "כל אחד" אומר רק שאפשר לפנות לכתובת — בלי קוד הגישה (שנגזר מהסיסמה) מקבלים שגיאה.

> כדי לא להדביק את כתובת ה-`/exec` בכל מכשיר מחדש, אפשר לכתוב אותה בשדה `driveUrl` בקובץ `assets/js/config.js`.

## חשוב לדעת (משפטי)

- הקבלות כוללות את כל הפרטים הנדרשים בקבלה של עוסק פטור לפי הוראות ניהול פנקסי חשבונות. פירוט בעמוד "תאימות לחוק" באתר.
- לפי הוראות ניהול ספרים, עסק שמפיק מסמכים ממוחשבים עשוי להידרש להשתמש בתוכנה רשומה ברשות המסים. **מומלץ לוודא מול רואה החשבון** שהשימוש במערכת מתאים לעסק שלך.
- תקרת עוסק פטור מוגדרת כברירת מחדל ל-120,000 ₪ — לעדכן בהגדרות לפי הסכום של כל שנה.

## מבנה הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | האתר |
| `assets/js/app.js` | ממשק המשתמש |
| `assets/js/store.js` | שמירה וטעינה (Google Drive + עותק מקומי) |
| `assets/js/drive.js` | החיבור ל-Apps Script |
| `assets/js/crypto.js` | הצפנה |
| `assets/js/receipt-doc.js` | עיצוב הקבלה, PDF והדפסה |
| `assets/js/legal.js` | תנאי שימוש, פרטיות, נגישות |
| `data/receipts.enc.json` | קובץ התחלתי ריק ומוצפן (הנתונים האמיתיים ב-Drive) |
| `google-apps-script/Code.gs` | הגשר ל-Google Drive |
| `tools/create-data.mjs` | יצירת קובץ נתונים ריק (לאיפוס בלבד) |

רכיבי צד שלישי: [html2pdf.js](https://github.com/eKoopmans/html2pdf.js) (MIT), [pdf.js](https://github.com/mozilla/pdf.js) (Apache-2.0, לייבוא קבלות קיימות), גופנים Heebo ו-Frank Ruhl Libre (SIL OFL) — כולם מאוחסנים מקומית באתר.
