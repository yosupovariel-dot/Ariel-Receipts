# מערכת הקבלות — אריאל יוסופוב עיצוב אתרים

אתר פרטי וסגור בסיסמה להפקת קבלות (עוסק פטור), עם שמירה מוצפנת ב-GitHub, גיבוי ל-Google Drive, הדפסה ושליחת PDF.

**כתובת האתר (אחרי הפעלת GitHub Pages):** https://yosupovariel-dot.github.io/Ariel-Receipts/

---

## מה יש במערכת

- **הפקת קבלה בשלושה צעדים** — לקוח, עבור מה, תשלום. תצוגה מקדימה חיה של הקבלה בזמן ההקלדה.
- **מספור אוטומטי ורציף** — מתחיל מ-80018, בלי דילוגים ובלי כפילויות.
- **קבלה לפי החוק** — כל הפרטים הנדרשים, "מקור" / "העתק נאמן למקור", חתימה. קבלה שהופקה לא נמחקת ולא נערכת — רק מבוטלת (עם חותמת "מבוטלת").
- **שליחה**: שיתוף PDF ישיר לוואטסאפ/מייל מהטלפון, הורדת PDF, הדפסה.
- **ארכיון מסודר** לפי שנים וחודשים, חיפוש, סיכום שנתי וייצוא לאקסל.
- **לקוחות** נשמרים אוטומטית — בפעם הבאה מקלידים שתי אותיות והפרטים מתמלאים.
- **שכפול** קבלה ללקוח קבוע בלחיצה אחת.
- **מעקב תקרת עוסק פטור** והתראה בהתקרבות.
- **Google Drive** — כל קבלה חדשה נשמרת אוטומטית כ-PDF בתיקיית השנה; הקבלות הקיימות ב-Drive מוצגות באתר.
- **נגישות** (ת"י 5568 / WCAG AA), תפריט נגישות, הצהרת נגישות, תנאי שימוש ומדיניות פרטיות.
- עובד מצוין בטלפון — אפשר "להוסיף למסך הבית" כמו אפליקציה.

קיצורי מקלדת: `N` — קבלה חדשה. `Ctrl+Enter` — הפקה.

## אבטחת מידע — איך זה עובד

- המאגר ב-GitHub **ציבורי**, ולכן **כל הנתונים מוצפנים** לפני שהם יוצאים מהדפדפן: AES-256-GCM, עם מפתח שנגזר מהסיסמה (PBKDF2-SHA256, 600,000 סבבים). בקובץ `data/receipts.enc.json` רואים רק ג'יבריש.
- **הסיסמה לא כתובה בשום מקום בקוד.** היא עצמה המפתח לפתיחת הנתונים.
- אין שחזור סיסמה — אם משנים אותה, לרשום במקום בטוח.
- כל שמירה היא commit ב-GitHub → יש היסטוריה מלאה ואפשר לשחזר כל גרסה. בנוסף יש עותק מוצפן בדפדפן, אפשרות לגיבוי ל-Drive, וייצוא גיבוי ידני.
- ניתוק אוטומטי אחרי 30 דקות ללא פעילות, נעילה זמנית אחרי 5 ניסיונות כניסה שגויים.

> המלצה: הסיסמה הנוכחית היא 9 ספרות בלבד. מומלץ להחליף (הגדרות ← אבטחה) לסיסמה ארוכה יותר עם אותיות — זה מחזק משמעותית את ההצפנה.

## הפעלה — פעם אחת (בערך 10 דקות)

### שלב 1: הפעלת האתר (GitHub Pages)

1. היכנס למאגר ב-GitHub ← **Settings** ← **Pages**.
2. תחת *Build and deployment*: Source = **Deploy from a branch**.
3. Branch: בחר את הענף הראשי של המאגר (כרגע `claude/affectionate-carson-8zq25h`, או `main` אם מיזגת אליו) ותיקייה `/ (root)` ← **Save**.
4. אחרי דקה-שתיים האתר יהיה זמין בכתובת: https://yosupovariel-dot.github.io/Ariel-Receipts/

### שלב 2: כניסה

- שם משתמש: `אריאל` (או `ariel`)
- הסיסמה שבחרת.

### שלב 3: חיבור GitHub לשמירה בענן (פעם אחת בכל מכשיר)

בלי זה הנתונים נשמרים רק בדפדפן של המכשיר. באתר: **הגדרות ← שמירה בענן** — יש שם הסבר מפורט:

1. [צור Fine-grained token](https://github.com/settings/personal-access-tokens/new).
2. Repository access: **Only select repositories** ← `Ariel-Receipts`.
3. Permissions ← Repository permissions ← **Contents: Read and write**.
4. העתק את הטוקן והדבק באתר. הוא נשמר מוצפן במכשיר בלבד.

### שלב 4: חיבור Google Drive

הסקריפט רץ **בחשבון הגוגל שלך** וניגש **רק לתיקיית הקבלות** שתגדיר — לא לשאר ה-Drive. באתר: **Drive** — שם מופיעות ההוראות וקוד סודי מוכן להעתקה. בקצרה:

1. פתח ב-Drive את תיקיית הקבלות הראשית (זו שבתוכה `2024`, `2025`…). מהכתובת `https://drive.google.com/drive/folders/XXXXXXXX` העתק את ה-`XXXXXXXX`.
2. כנס ל-[script.google.com](https://script.google.com/home/projects/create) ← פרויקט חדש ← הדבק את כל התוכן של [`google-apps-script/Code.gs`](google-apps-script/Code.gs).
3. מלא `FOLDER_ID` (מזהה התיקייה) ו-`SECRET` (הקוד שמופיע באתר).
4. שמור, בחר `testSetup` ← **Run** ← אשר הרשאות.
5. **Deploy ← New deployment ← Web app**. Execute as: **Me**. Who has access: **Anyone** ← Deploy.
6. העתק את כתובת ה-Web app והדבק באתר ← "חיבור ובדיקה".

מעכשיו: כל קבלה חדשה נשמרת אוטומטית ב-Drive בתיקיית השנה (התיקייה נוצרת לבד אם חסרה), והקבלות הקיימות מוצגות בעמוד Drive. ליד כל קובץ ישן יש כפתור "הוספה לסיכומים" כדי שהסיכום השנתי יכלול גם אותו.

> "Anyone" אומר שכל מי שיש לו את הכתובת יכול *לפנות* לסקריפט — אבל בלי הקוד הסודי הוא מקבל שגיאה ולא רואה כלום.

## חשוב לדעת (משפטי)

- הקבלות כוללות את כל הפרטים הנדרשים בקבלה של עוסק פטור לפי הוראות ניהול פנקסי חשבונות. פירוט בעמוד "תאימות לחוק" באתר.
- לפי הוראות ניהול ספרים, עסק שמפיק מסמכים ממוחשבים עשוי להידרש להשתמש בתוכנה רשומה ברשות המסים. **מומלץ לוודא מול רואה החשבון** שהשימוש במערכת מתאים לעסק שלך.
- תקרת עוסק פטור מוגדרת כברירת מחדל ל-120,000 ₪ — לעדכן בהגדרות לפי הסכום של כל שנה.
